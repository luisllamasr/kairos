## Design Principles

### Content First

The user's memories and content should always be the center of attention. The interface exists to support them, never to compete with them.

### Platform Native

Kairos should feel natural on every platform by respecting each operating system's interaction patterns and conventions while maintaining a consistent brand identity.

### Intentional Color

Color should communicate purpose. It should never be used as decoration alone.

### Calm Interface

Interfaces should feel spacious, balanced and free of unnecessary visual noise.

### Consistency

Similar problems should have similar solutions. Consistency is preferred over novelty.

### Emotion Through Content

Emotion comes from memories, places and people—not from excessive visual effects.
